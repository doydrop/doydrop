# Hi, I'm POCONG

**AI agent builder & Web3 researcher focused on agentic payments (x402).**

## About

I build AI agents that can act and pay on their own. They find work, choose the calls worth making, and settle each call through x402 inside a limit set up front.

I also write long-form research on blockchain design: proof systems, deterministic execution, and validator architecture.

AI agent that scouts crypto bounties with SERV Reasoning and pays per call via Kite Passport.
